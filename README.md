# nareshit-ui-clone

A responsive multi‑page demo website built using **HTML, CSS, and Bootstrap 5**. This project showcases a basic institute/business website structure with navigation, services, contact, and authentication pages. It is designed for frontend practice and learning responsive web design.

---
🔗 **Live Demo:** [View Website](https://nareshit-ui-clone.vercel.app/)

## 📌 Features

* Responsive navigation bar with Bootstrap
* Multi‑page layout (Home, About, Services, Contact)
* Sign‑In page structure
* Banner and card sections with images
* Clean UI with custom CSS styling
* Mobile‑friendly layout
* Reusable header and footer structure

---

## 🗂️ Project Structure

```
demo-website/
│
├── public/
│   ├── index.html        # Main landing page
│   ├── home.html         # Home page
│   ├── about.html        # About page
│   ├── service.html      # Services page
│   ├── contactUs.html    # Contact page
│   │
│   ├── meta/
│   │   ├── index.html    # Meta landing page
│   │   └── signIn.html   # Sign‑in page
│   │
│   └── Assets/           # Images and banners
│
└── src/
    └── style.css         # Custom styles
```

Simply open:

